Cloud Weather has two new patterns:

- **Cross & gather:** two pairs cross, then a drifting three-LED cloud gathers smaller ones. The slower loop lasts 20 seconds and is the default Cloud choice on a fresh install.
- **Slow convergence:** small clouds build into one eight-LED cloud. It moves to the left edge, returns to the right, and exits. Its loop lasts 48 seconds.

Both patterns can be previewed for their full duration. **Passing shadow** and **Passing shadows** remain available, and updating keeps your existing Cloud selection. The new patterns use neutral white with brightness variation, avoiding coloured edge pixels.

The Weather Country field now asks for a full name such as **France**. Two-letter codes do not work in this search; the no-results hint reflects that.

Download the attached ZIP and install it from **Decky Settings → Developer → Install Plugin from ZIP**. Automated tests pass; the new motion still needs feedback from the physical Steam Machine bar.
